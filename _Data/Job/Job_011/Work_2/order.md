# 업무지시서

## 1. 전체 버튼 보유 프리셋 조회

**대상 스킬**: 게임개발_프리셋_파일_질문

**"question"**: 모든 프리셋에서 Unity UI `Button`을 보유한 노드와 현재 전환 설정·Animator 연결을 전수 확인한다.

**업무**

- `컨트롤`·`팝업`·`애드온`·오브젝트 프리팹에서 `Button` 컴포넌트를 가진 노드를 찾는다.
- 각 버튼의 `transition`, `animationTriggers`, `Animator.runtimeAnimatorController`와 `Animator_Button` 에셋 존재를 실측한다.
- 프리팹별 `reuse`·`confirmed`·원본 경로를 조회하되 값을 변경하지 않는다.

## 2. 컨트롤 버튼 Animator 통일

**대상 스킬**: 게임개발_프리셋_파일_컨트롤_구성

**"content"**: 조회된 모든 컨트롤 버튼의 전환 애니메이션을 `Animator_Button`으로 통일한다.

**업무**

- 버튼 전환 모드를 `Animation`으로 설정하고 동일 노드의 `Animator`에 `Animator_Button`을 연결한다.
- 기존 클릭 배선·레이아웃·표시 값을 보존한다.
- 대상 컨트롤이 없으면 조회 근거와 조건을 보고하고 건너뛴다.

## 3. 팝업 버튼 Animator 통일

**대상 스킬**: 게임개발_프리셋_파일_팝업_구성

**"content"**: 조회된 모든 팝업 버튼의 전환 애니메이션을 `Animator_Button`으로 통일한다.

**업무**

- 버튼 전환 모드를 `Animation`으로 설정하고 동일 노드의 `Animator`에 `Animator_Button`을 연결한다.
- 기존 클릭 배선·레이아웃·표시 값을 보존한다.
- 대상 팝업이 없으면 조회 근거와 조건을 보고하고 건너뛴다.

## 4. 기타 프리셋 버튼 Animator 통일

**대상 스킬**: 게임개발_프리셋_파일_애드온_구성

**"content"**: 조회된 애드온 버튼의 전환 애니메이션을 `Animator_Button`으로 통일한다.

**업무**

- 애드온에 버튼이 있을 때만 같은 전환 모드와 Animator 연결을 적용한다.
- 오브젝트 프리팹에서 버튼이 발견되면 `게임개발_프리셋_파일_오브젝트_구성`으로 동일 항목을 이어 수행한다.
- 대상이 없으면 조회 근거와 조건을 보고하고 건너뛴다.

## 5. 변경 프리셋 export

**대상 스킬**: 게임개발_프리셋_파일_익스포트

**"presetTarget"**: 버튼 설정이 변경된 프리셋 전체

**업무**

- 변경한 프리셋 원본을 각각 export하고 재임포트 성공을 확인한다.
- 노드 생성·프리셋 생성·코드 작성·컴파일 체인은 새 구조나 스크립트 변경이 없어 제외한다.
- 컨셉·모듈·리소스 질문 체인은 사용자가 기존 `Animator_Button` 적용값을 지정했고 새 계약이 없어 제외한다.

## 6. 변경 프리셋 재임포트

**대상 스킬**: 유니티엔진_재임포트_실행

**"changedPaths"**: 버튼 Animator 설정이 변경된 컨트롤·팝업 프리팹

**업무**

- 익스포트 사본을 Unity에 재임포트하고 변경 프리팹 경로가 정상 인식되는지 확인한다.
- 열린 씬의 기존 변경은 저장하지 않고 보존한다.
