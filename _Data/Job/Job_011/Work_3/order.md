# 업무지시서

## 1. 프레임형 팝업 애니메이션 전수 조회

**대상 스킬**: 게임개발_프리셋_파일_질문

**"question"**: `Popup_Notify`의 4종 팝업 애니메이션 구성과 모든 프레임형 팝업의 현재 적용 상태를 전수 확인한다.

**업무**

- `Popup_Notify`가 보유한 팝업 애니메이션 4종의 프리셋 ID·대상 노드·열기·닫기 값을 실측한다.
- `Game` 네임스페이스 팝업 중 프레임을 가진 대상을 전수 식별하고 4종별 누락·값 차이를 기록한다.
- `reuse`·`confirmed`와 원본 경로를 조회하되 값을 변경하지 않는다.

## 2. 전체 프레임형 팝업 4종 애니메이션 통일

**대상 스킬**: 게임개발_프리셋_파일_팝업_구성

**"content"**: 모든 `Game` 프레임형 팝업에 `Popup_Notify`와 같은 4종 팝업 애니메이션을 유사한 값으로 구성한다.

**업무**

- 조회된 각 프레임형 팝업에 `Popup_Notify` 기준 4종 애니메이션 인스턴스를 모두 배치한다.
- Blocker 계열 효과는 Blocker에, 프레임 계열 효과는 실제 프레임 루트에 연결한다.
- 열기·닫기 방향, 회전, 크기, 알파 변화는 `Popup_Notify` 실측값을 기준으로 하고 각 프레임 크기에 필요한 최소 차이만 허용한다.
- 기존 버튼·레이아웃·팝업 입력 배선과 `confirmed`·`reuse`를 보존한다.

## 3. 변경 팝업 익스포트

**대상 스킬**: 게임개발_프리셋_파일_익스포트

**"presetTarget"**: 4종 애니메이션 구성이 변경된 `Game` 팝업 전체

**업무**

- 변경된 팝업을 각각 익스포트하고 오류가 없는지 확인한다.
- 라이브러리의 `Popup_Notify`는 기준 조회만 하고 수정하지 않는다.
- 노드·프리셋 생성과 코드·컴파일 체인은 기존 애니메이션 프리셋 인스턴스만 배치하므로 제외한다.
- 완료 근거는 `c04`에 대응한다.
