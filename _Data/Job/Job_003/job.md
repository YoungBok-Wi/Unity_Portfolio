# Job_003 업무 맥락

## 목적

개선 루프 2회차(사용자 지시 "한 번만 더") — Job_002 재평가(`_Data/Job/Job_002/Work_7/result.md` `## 비고`) 결함 10건(체감 6·미관 4)을 영역별로 합쳐 일괄 수정하고 전 범위 재평가·커밋한다. 종료 시 `AskUserQuestion`으로 다음 방향을 묻는다.

## 운영 규칙

- 회차 1 Job, 컨셉 → 리소스 → 모듈 → 데이터 → 프리셋 → 씬 → 플레이테스트 → 커밋 1루프 (데이터를 모듈 뒤에 둔 이유: `Quit` 모듈 `inAsset` 활성 후 `Text` 익스포트가 필요)
- 자율 진행, 실행 모드 `일반`, 안정화 우선

## 수정 범위

- 컨셉: Gun 무입력 생존 목표 정의, 적·보스 스프라이트 피벗 정본(컨셉 0.28 vs 임포트 BottomCenter) 확정, 보스 전조 형태(바닥 타원) 규격
- 리소스: 적·보스 프레임 임포트 피벗을 정본대로 재익스포트(부유 해소)
- 모듈: 플레이어 접지 판정(`CharacterPhysics2DSide.cs` 접지 조건 vs 하단 피벗 — 정본 결정 후 라이브러리 또는 플레이어 콜라이더 오프셋), 적 접촉 밀림(레이어 충돌 매트릭스·물리 해소), 웨이브 스폰 벽 안 클램프, 로비 BGM 재생(`Scene_Lobby` 로컬 매니저), 해금 완료 문구 ID 교체(`LocalRoomManager`), `Telegraph.prefab` 바닥 타원 형태, `Quit` 모듈 `inAsset` 켜기
- 데이터: 해금 완료 문구 ID 신설(`Text_Core_GunUnlocked`), `Text` 재익스포트(`Popup_Quit` ID 해소)
- 프리셋: `Popup_Result` 해금 라벨 ID 교체, 플레이어 프리팹 콜라이더 오프셋(정본이 프리팹 쪽이면), Gun 시트 표시 확인
- 씬: 셋업으로 소멸한 `[Local]` 오버라이드(카메라 4.0·스폰 위치) 재적용·검증(Job_002 Work_6 레포트 절차)
- QA: 전 시나리오 재평가·안정화 판정
- 깃: 커밋·푸시

## 체인묶음 대응

- [컨셉] 기준 `게임개발_구성_컨셉_게임_작성`: 컨셉_질문 → 게임_작성 → 검증 → 밸런스_작성 → 검증 → 리소스_작성 → 검증 (씬설정 변경 없으면 셋업 생략)
- [리소스] 기준 `게임개발_구성_리소스_파일_익스포트`: 리소스_질문 → 타입_구성(피벗) → 파일_익스포트 → 재임포트
- [모듈] 기준 `게임개발_모듈_폴더_작성`: 모듈_폴더_구성(Quit inAsset) → 모듈_폴더_작성 → 컴파일 → 익스포트
- [데이터] 기준 `게임개발_구성_데이터_테이블_작성`: 데이터_질문 → 테이블_작성 → 익스포트
- [프리셋] 기준 `게임개발_프리셋_파일_팝업_코드_작성`: 코드 작성 → 컴파일 → 구성 → 익스포트
- [유니티엔진] 기준 `유니티엔진_씬_구성`: 씬_질문 → 씬_구성 → 씬_검증
- [유니티게임QA] 기준 `QA_유니티게임개발_플레이테스트_테스트`: 질문 → 계획 → 치트 → 테스트
- [깃] 기준 `깃_커밋_실행`: 커밋 → 푸시
