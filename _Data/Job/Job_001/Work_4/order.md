# 업무지시서

## 1. 기존 모듈 재사용 켜기

**대상 스킬**: 게임개발_모듈_폴더_구성

**"taskContent"**: 게임에 필요한 `inAsset=false` 기존 모듈을 `Assets`로 재포함하고 신규 게임 모듈 메타 확정

**업무**

- 선행 `게임개발_모듈_폴더_생성`은 Work_1이 등록한 신규 모듈이 누락된 경우에만 수행한다 (Work_1 레포트의 등록 모듈 ID 참조)
- `inAsset=false` 모듈 중 재사용 대상을 켠다: `FSM`(보스·적 상태 기계), `CharacterPhysics`(사이드뷰 이동·접지), `Delegate`(값 갱신 분산), `Bank`(런 재화), `ObjectPool`(투사체·적 풀링). `Lv`·`Quest`·`Link`·`Statis`는 `씬설정` "사용 모듈"에 있을 때만 켠다
- 켠 뒤 `유니티엔진_컴파일_실행`으로 의존 코드 컴파일 통과를 확인한다
- 신규 게임 모듈(방 진행·전투·캐릭터 해금 등, Work_1 확정 목록)의 설명·소속 노드 메타를 확정한다

## 2. 게임 모듈 코드 작성

**대상 스킬**: 게임개발_모듈_폴더_작성

**"taskContent"**: 신규 게임 모듈의 설계 문서·스크립트·매니저 프리팹 작성

**업무**

- 대상: Work_1이 등록한 게임 고유 모듈 전체 (기획 → 코드 → 프리팹 순)
- 기능 요구:
  - 방 진행: 선택지 세트 4종([전투/회복]·[회복/능력]·[전투/보스]·[전투/전투]) 랜덤 제시, 선택·입장·클리어 판정, 지나온 방 이력 기록, 다음 방 적 구성 미리보기 데이터 제공, 보스방 클리어 시 런 종료
  - 전투: 피해·HP·사망 처리, 웨이브 스폰(테이블 기반), 검 근접 판정·총 투사체, 능력 강화 적용(Factor 활용)
  - 캐릭터 해금: 5번째 방 클리어 시 총 캐릭터 영구 해금(`Save` 연동), 로비 선택 상태 저장
  - 적·보스 AI: `FSM` 모듈 기반. 일반 적 3종(근접 추격·공격 / 탱커 저속 고체력·돌진 / 원거리 거리 유지·투사체), 보스 2종은 상태 3개 이상의 패턴 순환과 체력 구간별 전환
- 기존 모듈 API(`Value`·`Number`·`Deal`·`Popup`·`Sound`·`Table`·`Save`)를 재사용하고 중복 구현을 만들지 않는다. 데이터 값은 Work_2 익스포트 산출(테이블·고정값 코드)만 참조한다
- 오브젝트 전용 스크립트(플레이어·적·보스 프리팹 스크립트)는 Work_5 담당이므로 모듈은 공용 로직·매니저·인터페이스까지만 작성한다
- 후속 `유니티엔진_컴파일_실행` 통과 후 `게임개발_모듈_폴더_익스포트`로 원본을 반영한다
- 완료 기준: 컴파일 에러 0건, 익스포트·재임포트 성공. `confirmed`·`reuse` 값은 변경하지 않으며 막힘은 우회하지 않고 보고한다
