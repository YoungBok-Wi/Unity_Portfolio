# 업무지시서

## 1. 리소스 타입·이미지 제작

**대상 스킬**: 게임개발_구성_리소스_타입_생성

**"taskContent"**: `리소스컨셉`이 신규 제작으로 지정한 이미지(배경·방 아이콘·투사체·UI 보강)의 타입 등록·구성·제작·업로드·익스포트

**업무**

- 선행 `게임개발_구성_리소스_질문`으로 `리소스컨셉`(Work_1 산출)의 제작 목록과 등록 현황을 조회한다. 기존 `inAsset` 리소스(`UI_Casual_*`·`Icon_Casual_*`·`Illust_Casual_*`)로 충족되는 항목은 제작하지 않고 재사용으로 보고한다
- 같은 용도의 타입이 있으면 생성을 건너뛰고 `게임개발_구성_리소스_타입_구성`부터 진행한다
- 제작 대상 예: 사이드뷰 배경(로비 1, 전투·회복·능력·보스 방 각 1), 방 종류 아이콘 4종, 원거리 적 투사체, 보스 투사체·경고 표시
- 체인 순서: 타입 생성 → 타입 구성 → 타입 업로드(기본값 파일 필요 시) → 파일 생성 → 파일 구성 → `게임개발_구성_리소스_파일_이미지_제작` → 파일 업로드 → `게임개발_구성_리소스_파일_익스포트`
- 완료 기준: 제작 파일이 `inAsset` 켜진 상태로 `Assets` 경로에 익스포트되고 임포트 에러 0건

## 2. 캐릭터·적·보스 애니메이션시트 제작

**대상 스킬**: 게임개발_구성_리소스_파일_애니메이션시트_제작

**"taskContent"**: 플레이어 공격 모션(검·총)과 보스 2종·부족한 적 모션의 2D 애니메이션시트 제작·업로드·익스포트

**업무**

- 선행 `게임개발_구성_리소스_질문`으로 `AnimationSheet_Casual_Player`(Move만 있음)·`AnimationSheet_Casual_Enemy`(Apple·Banana·Orange·Watermelon의 Move·Die) 현황을 조회한다
- 제작 목록 (기존과 화풍·크기 규격 일치): 플레이어 Idle·Attack_Knife·Attack_Gun·Hit·Die, 근접 적(Apple)·탱커(Watermelon)·원거리 적(Banana) Attack, 보스 2종 Idle·Move·Attack 패턴별·Die
- 파일 entry가 없으면 `게임개발_구성_리소스_파일_생성` → `게임개발_구성_리소스_파일_구성`으로 프롬프트를 확정한 뒤 제작한다
- 체인 순서: 파일 생성 → 파일 구성 → 애니메이션시트 제작 → 파일 업로드 → 파일 익스포트
- 완료 기준: 각 시트가 분할 프레임으로 업로드·익스포트되고 임포트 에러 0건. `confirmed`·`reuse` 값은 변경하지 않으며, 제작 도구 실패는 우회하지 않고 대상·에러 원문을 보고한다
