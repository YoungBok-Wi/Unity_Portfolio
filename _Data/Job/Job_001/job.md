# Job_001 업무 맥락

## 지시 원문

포트폴리오용으로 사용하게 오래걸려도 좋으니까 최대한 좋은 퀄리티로 꼼꼼하게 게임을 만들어줘 완성 후 계속 루프돌면서 개선 진행해줘

게임은
씬은 로비/게임씬 두개로 해줘
사이드뷰 액션게임이고
캐주얼 그래픽이야
전투 / 몬스터 / 보스가 있고
해금 요소가 있어, 검을 쓰는 캐릭터, 총을 쓰는 캐릭터 두가지야 처음엔 검만 가능하고, 5번째 방 클리어시 총을 쓰는 캐릭터 해금을 넣어줘
한 방을 클리어하면 랜덤한 다음 방을 선택해서 넘어 갈 수 있고, 지나온 방을 확인 가능해
방 이동시에는 [전투방/회복방], [회복방/능력방], [전투방/보스방], [전투방/전투방] 이렇게중에 선택지가 랜덤이야
다음 방에 나오는 적은 미리 확인 가능해 적은 근거리 공격형/탱킹형, 원거리 이렇게 일반 적이 있고 보스는 2종이고 FSM으로 패턴 있게 만들어줘

그 외의 요소들은 알아서 채워주고
자율적으로 진행해주고
오케스트레이션은 일반모드로 진행해줘

추가 지시: 만들때 기존 모듈들도 활용해줘 inasset=false해둔 모듈들 꺼내서

## 업무 목표

- 로비(`Lobby`)·게임(`Game`) 2씬의 2D 사이드뷰 캐주얼 로그라이트 액션 게임을 포트폴리오 품질로 완성한다
- 완성 후 플레이테스트 → 결함 수정 → 커밋을 반복하는 개선 루프를 이어간다

## 요구 항목

- 캐릭터 2종: 검(초기 사용 가능), 총(5번째 방 클리어 시 해금, 영구 저장)
- 방 진행: 클리어 후 2택 랜덤 선택지 — [전투/회복], [회복/능력], [전투/보스], [전투/전투] 중 랜덤. 지나온 방 이력 확인 UI. 다음 방 적 구성 미리보기
- 일반 적 3종: 근접 공격형, 탱킹형, 원거리형
- 보스 2종: FSM 기반 패턴
- 기타 요소(회복량·능력 강화 종류·재화·저장 등)는 오케스트레이터가 채움

## 의존 관계

1. 컨셉(게임→밸런스→리소스→씬설정) → 씬 파일·모듈/프리셋 골격·씬 셋업
2. 데이터 테이블·고정값 (컨셉 확정 후)
3. 리소스 타입·이미지·애니메이션시트 (리소스컨셉 확정 후)
4. 모듈 코드 (데이터 익스포트 후) — 기존 `inAsset=false` 모듈은 `게임개발_모듈_폴더_구성`으로 켜서 재사용
5. 프리셋 팝업·오브젝트 코드·구성 (모듈·리소스 후)
6. 플레이테스트 → 커밋 → 개선 루프

## 제약

- 실행 모드: `일반`
- 자율 진행 (사용자 확인 최소화)
- 기존 모듈 재사용 우선 — 새 모듈 생성 전 `inAsset=false` 모듈 목록 조회 필수
