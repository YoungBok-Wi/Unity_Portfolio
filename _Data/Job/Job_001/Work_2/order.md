# 업무지시서

## 1. 데이터 테이블 구조·값 작성

**대상 스킬**: 게임개발_구성_데이터_테이블_구성

**"taskContent"**: Work_1이 등록한 게임 데이터 테이블 골격에 필드 구조와 행 값을 작성하고 익스포트

**업무**

- 선행 `게임개발_구성_데이터_질문`으로 등록된 테이블 목록·골격을 조회한다. Work_1 결과 레포트(`_Data/Job/Job_001/Work_1/result.md`)의 등록 테이블 ID를 대상으로 삼는다
- 테이블 골격이 누락돼 있으면 `게임개발_구성_데이터_테이블_생성`으로 먼저 등록한다
- 필드 구조: `밸런스컨셉`의 수치 기준을 그대로 담는다 — 캐릭터(무기 종류·HP·공격력·공격속도·이동속도·사거리·해금 조건), 적(종류·HP·공격력·이동속도·사거리·행동 파라미터), 보스(FSM 상태별 패턴 파라미터), 방(종류·아이콘·설명), 웨이브(방 순번 구간별 적 구성), 능력(종류·수치·아이콘)
- 행 값: `게임개발_구성_컨셉_질문`으로 `밸런스컨셉`·`게임컨셉` 기대값을 확인해 `게임개발_구성_데이터_테이블_작성`으로 입력한다. 아이콘 등 리소스 참조값은 기존 `inAsset` 리소스명(`Icon_Casual_Weapon/Knife`·`Gun`, `Icon_Casual_Upgrade/*`)을 우선 사용하고 실측한다
- 표시 텍스트는 `Text` 테이블 행으로 등록한다 (캐릭터·적·보스·방·능력 이름과 설명, 한국어·영어)

## 2. 데이터 고정값 정의·값 작성

**대상 스킬**: 게임개발_구성_데이터_고정값_구성

**"taskContent"**: Work_1이 등록한 고정값 골격의 타입·설명 정의와 값 입력

**업무**

- 선행 `게임개발_구성_데이터_질문`으로 고정값 등록 현황을 조회하고, 누락분은 `게임개발_구성_데이터_고정값_생성`으로 등록한다
- 대상 예: 총 해금 방 순번(5), 방 선택지 세트 4종, 회복방 회복 비율, 능력 선택지 개수(3), 보스 등장 최소 방 순번, 런 최대 방 수
- 값은 `밸런스컨셉` 기대값과 일치시키고 `게임개발_구성_데이터_고정값_작성`으로 입력한다

## 3. 데이터 익스포트

**대상 스킬**: 게임개발_구성_데이터_익스포트

**"taskContent"**: 타입·테이블·고정값·텍스트 전 종류 익스포트로 구조 코드·런타임 값 반영

**업무**

- 업무 1·2 확정분을 한 번에 익스포트한다
- 완료 기준: 익스포트 성공과 Unity 컴파일 에러 0건. `confirmed`·`reuse` 값은 변경하지 않는다
