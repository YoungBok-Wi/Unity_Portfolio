# 업무지시서

## 1. 보스 미완 동작·플레이어 추가 동작 애니메이션시트 제작

**대상 스킬**: 게임개발_구성_리소스_파일_애니메이션시트_제작

**"taskContent"**: Work_3에서 Codex 사용량 한도로 미완된 보스 2동작 마무리와 `리소스컨셉` 규격의 플레이어 추가 동작 제작·업로드·익스포트

**업무**

- 사전 확인: `codex_image` `Work_0037`(`AnimationSheet_Casual_Boss/Pumpkin_Attack2`)·`Work_0038`(`Pineapple_Idle`) 상태를 조회한다. `Completed`면 산출 검수(체커보드 배경이 구워진 불투명 PNG면 불합격)·분할·정렬부터 잇고, `Failed`·`Pending`이면 한도 해제(사용량 한도 메시지 기준 07:34 이후) 후 재생성한다. 한도가 아직이면 재시도 예정 시각까지 기다렸다가 진행하며, 우회 도구로 바꾸지 않는다
- 플레이어 추가 동작 (`리소스컨셉` 애니메이션 규격 절 기준, 기존 `AnimationSheet_Casual_Player` 256x256 규격·화풍 일치): `Jump`, 검 3단 콤보 `Attack1`·`Attack2`·`Attack3` (기존 `Attack_Knife`는 `Attack1`로 재사용 가능하면 재제작하지 않고 레포트에 대응을 적는다), 총 `Shoot`(기존 `Attack_Gun`으로 대체 가능하면 동일)
- 체인: `게임개발_구성_리소스_질문`(현황) → 파일 생성(없는 entry만) → 파일 구성 → 애니메이션시트 제작 → 파일 업로드 → `게임개발_구성_리소스_파일_익스포트` → 재임포트
- 완료 기준: 대상 전 동작이 분할 프레임으로 `Resources/SpriteAnim`에 익스포트되고 `.meta` 실재·콘솔 에러 0건

## 2. 누락 Illust entry 제작

**대상 스킬**: 게임개발_구성_리소스_파일_생성

**"taskContent"**: `리소스컨셉`이 재사용으로 지정했으나 entry가 없는 연출 이미지 5건 등록·제작·익스포트

**업무**

- 대상: `Illust_Casual_Hit/Impact`(타격 이펙트), `Illust_Casual_Slash/Knife`(검 궤적), `Illust_Casual_Splatter/Death`(사망 연출), `Illust_Casual_Shadow/Ellipse`(발밑 그림자), `Illust_Casual_Tile/Kitchen`(바닥 타일) — 타입은 실재하므로 `게임개발_구성_리소스_질문`으로 타입 출력 슬롯·규격을 확인하고 필요 시 `게임개발_구성_리소스_타입_구성`으로 프롬프트를 사이드뷰·캐주얼로 보정한다
- 체인: 파일 생성 → 파일 구성 → `게임개발_구성_리소스_파일_이미지_제작` → 파일 업로드 → 파일 익스포트 → 재임포트
- 완료 기준: 5건이 `inAsset` 켜진 상태로 익스포트되고 임포트 에러 0건
- 비고: 사용자가 자율 진행을 지시했으므로 프롬프트·규격 판단은 스스로 확정한다. `confirmed`·`reuse` 값은 변경하지 않으며, 제작 도구 실패는 우회하지 않고 대상·에러 원문을 레포트 `## 예외상황`에 남긴다
