# 업무지시서

## 1. 프리셋 현황·골격 확인

**대상 스킬**: 게임개발_프리셋_파일_질문

**"taskContent"**: 씬설정이 등재한 팝업·컨트롤·오브젝트의 더미 골격(Work_1 산출)과 재사용 가능한 기존 프리셋 확인

**업무**

- 팝업·컨트롤·오브젝트 노드 트리와 규칙이 없으면 `게임개발_프리셋_노드_생성` → `게임개발_프리셋_노드_구성`으로 먼저 만든다
- `게임개발_구성_컨셉_질문`·`게임개발_모듈_질문`·`게임개발_구성_리소스_질문`으로 컨셉 정의·모듈 API·리소스 준비 상태를 확인하고, 미등록 프리셋은 `게임개발_프리셋_파일_생성`으로 골격을 만든다
- 기존 `Popup_Setting`·`Popup_Notify`·`Popup_NotifyUI`·`Popup_BlockingUI`는 재사용한다

## 2. 팝업·컨트롤 코드 작성

**대상 스킬**: 게임개발_프리셋_파일_팝업_코드_작성

**"taskContent"**: 로비·게임 씬 팝업과 그 안의 컨트롤 전용 스크립트 로직 작성

**업무**

- 로비: 캐릭터 선택(검·총, 잠금 표시·해금 조건 안내), 게임 시작, 설정 진입
- 게임: HUD(HP 게이지·현재 방 순번·지나온 방 이력 목록), 방 선택 팝업(2택 선택지 + 각 방의 적 구성 미리보기 아이콘·이름), 능력 선택 팝업(3택1), 일시정지, 결과 팝업(클리어·게임오버, 해금 알림, 로비 복귀)
- 컨트롤(`게임개발_프리셋_파일_컨트롤_코드_작성`): 방 선택지 카드, 방 이력 항목, 능력 카드, 적 미리보기 항목. 애드온은 필요 시에만 `게임개발_프리셋_파일_애드온_코드_작성`으로 작성한다
- MCP 플레이 상태·조작 override(`MCPDetail`·`MCPInteraction`·`MCPInteract`·치트)를 팝업마다 작성한다 (Work_6 플레이테스트가 사용)
- 조작 요소는 `[SerializeField]` 필드로 선언한다

## 3. 오브젝트 코드 작성

**대상 스킬**: 게임개발_프리셋_파일_오브젝트_코드_2D_사이드뷰_캐릭터_작성

**"taskContent"**: 플레이어 2종·일반 적 3종·보스 2종·투사체 오브젝트 전용 스크립트 작성

**업무**

- 2D 사이드뷰 규칙(좌우 반전·접지·이동 축·모션 전환·공격 판정)을 따른다. 물리는 `CharacterPhysics` 모듈, 상태는 `FSM` 모듈, 공용 로직은 Work_4 모듈 API를 사용한다
- 플레이어: 이동·점프·검 3단 콤보 / 총 연사, 피격·사망 모션
- 적 3종·보스 2종: FSM 상태 전환과 애니메이션 연결, 보스는 패턴별 예고 연출
- 배경·바닥·투사체는 일반 `게임개발_프리셋_파일_오브젝트_코드_작성`으로 작성한다
- 후속 `유니티엔진_컴파일_실행`으로 통과를 확인한다

## 4. 프리셋 구성·익스포트

**대상 스킬**: 게임개발_프리셋_파일_팝업_구성

**"taskContent"**: 코드가 선언한 필드를 노드에 배선하고 프리팹 원본을 익스포트

**업무**

- 팝업 구성 → 컨트롤 구성(`게임개발_프리셋_파일_컨트롤_구성`) → 애드온 구성(있을 때) → 오브젝트 구성(`게임개발_프리셋_파일_오브젝트_구성`: 스프라이트·애니메이터·콜라이더·리지드바디 배선, Work_3 애니메이션시트 사용) 순으로 수행한다
- UI는 기존 `UI_Casual_*` 리소스로 레이아웃을 구성하고 캐주얼 화풍을 유지한다
- 마지막에 `게임개발_프리셋_파일_익스포트`로 반영하고, 씬에 반영이 필요한 항목은 `유니티엔진_씬_셋업_실행`으로 두 씬에 등재한다
- 완료 기준: 컴파일 에러 0건, 익스포트·재임포트 성공, 두 씬 플레이 진입 시 에러 0건. `confirmed`·`reuse` 값은 변경하지 않으며 막힘은 우회하지 않고 보고한다
