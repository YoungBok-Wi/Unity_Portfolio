# 업무지시서

## 1. Attack2 리소스 원본과 반영 구조 조회

**대상 스킬**: 게임개발_구성_리소스_질문

**"question"**: `AnimationSheet_Casual_Player_Attack2_01`~`06`의 등록 ID, 원본 경로, 출력 경로, `reuse`·`inAsset`·선택 슬롯을 조회한다.

**업무**
- 여섯 프레임의 실제 PNG 경로와 원본·사본 관계를 확정한다.
- 픽셀 크기와 알파 채널을 반전 전 기준값으로 기록한다.

## 2. 검증된 이미지 반전 자동화 조회

**대상 스킬**: AI구성_자동화_질문

**"question"**: PNG의 픽셀·알파·크기를 보존하며 X축으로 좌우 반전하는 기존 자동화와 입력 계약을 조회한다.

**업무**
- 적합한 기존 자동화가 있으면 그 ID와 입력 형식을 확정한다.
- 적합한 자동화가 없으면 다른 가공 수단으로 우회하지 않고 예외로 보고한다.

## 3. Attack2 프레임 좌우 반전

**대상 스킬**: AI구성_자동화_실행

**"input"**: 업무 1의 여섯 원본 PNG를 업무 2에서 확정한 자동화로 X축 반전한다.

**업무**
- 여섯 파일 모두 오른쪽을 향하도록 좌우 반전한다.
- 파일 크기·해상도·알파·색·프레임 순서와 ID는 유지한다.
- 실행 결과에서 여섯 출력 파일의 성공 여부를 확인한다.

## 4. 반전 리소스 반영

**대상 스킬**: 게임개발_구성_리소스_파일_업로드

**"sourcePath"**: 업무 3의 반전 출력 파일 6개

**업무**
- `reuse`에 따른 원본 위치를 지키며 기존 여섯 리소스의 새 산출물로 반영한다.
- 기존 `confirmed`·`reuse`·ID를 변경하지 않는다.
- 자동화가 원본을 직접 수정해 별도 업로드가 필요 없으면 대상·조건·실측 근거를 보고한다.

## 5. Attack2 리소스 익스포트와 재임포트

**대상 스킬**: 게임개발_구성_리소스_파일_익스포트

**"resourceFileId"**: 업무 1에서 확정한 `AnimationSheet_Casual_Player_Attack2_01`~`06`의 개별 ID

**업무**
- 여섯 리소스를 각각 익스포트하고 Unity 재임포트를 완료한다.
- 최종 PNG의 해상도·알파와 방향을 확인한다.
- 신규 리소스 생성·프롬프트 구성·생성형 애니메이션시트 제작은 기존 프레임의 결정론적 반전 요구와 맞지 않아 제외한다.
- `유니티엔진_씬_검증`은 사용자 지시에 따라 실행하지 않는다.
