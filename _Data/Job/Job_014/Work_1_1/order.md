# 업무지시서

## 1. X축 반전 자동화 중복 확인

**대상 스킬**: AI구성_자동화_질문

**"question"**: `image_flip_horizontal` 등록 여부와 재사용 가능한 동일 기능 자동화를 다시 확인한다.

**업무**
- 기존 조회 결과와 현재 등록 상태를 대조해 중복 생성을 막는다.

## 2. X축 반전 자동화 생성

**대상 스킬**: AI구성_자동화_생성

**"automationId"**: `image_flip_horizontal`

**"automationType"**: `Default`

**업무**
- PNG 입력들을 좌우 반전해 별도 출력하는 범용 자동화 골격을 생성한다.
- 프로젝트 고유 경로는 입력값으로 받고 공용 원본에 하드코딩하지 않는다.

## 3. X축 반전 자동화 메타 구성

**대상 스킬**: AI구성_자동화_구성

**"automationId"**: `image_flip_horizontal`

**업무**
- 이미지의 픽셀 크기·RGBA·파일 순서를 보존하는 X축 반전 용도를 설명에 기록한다.
- `confirmed`는 변경하지 않고 실행 설정은 기존 Default 규약을 따른다.

## 4. X축 반전 자동화 본문 작성

**대상 스킬**: AI구성_자동화_작성

**"automationId"**: `image_flip_horizontal`

**"content"**: 입력 PNG 목록을 Pillow의 좌우 반전으로 처리하고 원본 파일명으로 출력 폴더에 저장한다.

**업무**
- 입력 명세와 `main.py`를 표준 템플릿에 맞춰 작성한다.
- 입력 누락·비PNG·디코딩 실패는 대상 경로가 드러나는 오류로 종료한다.
- 출력 PNG의 모드·해상도·알파를 원본과 동일하게 보존하고 원본 파일을 덮어쓰지 않는다.

## 5. X축 반전 자동화 검증

**대상 스킬**: AI구성_자동화_검증

**"automationId"**: `image_flip_horizontal`

**업무**
- 입력 명세와 Python 본문의 자동 검증을 통과한다.
- 워크플로우 스킬 문서 작성은 새 자동화를 별도 스킬에 결선하는 요구가 없어 제외한다.
