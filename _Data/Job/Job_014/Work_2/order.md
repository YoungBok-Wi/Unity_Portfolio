# 업무지시서

## 1. 총기 점프 애니메이션 원인 조회

**대상 스킬**: 게임개발_프리셋_파일_질문

**"question"**: `Object_Player_Gun`의 점프 액션 요청명·클립명·프레임과 `Object_Player_Gun.ResolveAnim`을 대조한다.

**업무**
- `Object_Player_Gun`과 칼 플레이어의 점프 클립 배선을 비교한다.
- 총기 플레이어가 칼 캐릭터 공용 점프 프레임을 재생하는 정의처를 확정한다.

## 2. 총기 전용 점프 리소스 조회

**대상 스킬**: 게임개발_구성_리소스_질문

**"question"**: 기존 `AnimationSheet_Casual_Player_Jump_Gun` 계열 프레임의 등록·출력 상태를 조회한다.

**업무**
- 실재하는 총기 전용 점프 프레임과 순서를 확정한다.
- 리소스가 없으면 임의 생성·공용 프레임 재사용으로 우회하지 않고 결손을 보고한다.

## 3. 총기 점프 액션명 분기 작성

**대상 스킬**: 게임개발_프리셋_파일_오브젝트_코드_작성

**"objectId"**: `Object_Player_Gun`

**업무**
- 총기 플레이어의 `Jump` 요청을 전용 `Jump_Gun` 액션으로 변환한다.
- 기존 `Idle_Gun`·`Move_Gun` 분기와 다른 캐릭터 동작을 보존한다.

## 4. 총기 플레이어 코드 컴파일

**대상 스킬**: 유니티엔진_컴파일_실행

**"changedPaths"**: 업무 3에서 수정한 총기 플레이어 전용 스크립트

**업무**
- Unity 재컴파일 완료와 컴파일 에러 부재를 확인한다.

## 5. Object_Player_Gun 점프 클립 배선

**대상 스킬**: 게임개발_프리셋_파일_오브젝트_구성

**"prefabId"**: `Object_Player_Gun`

**"content"**: 기존 총기 전용 점프 프레임을 `Jump_Gun` 클립으로 배선한다.

**업무**
- 현재 `SpriteAnimPlayer` 전체 조회값을 보존한 수정으로 `Jump_Gun`을 구성한다.
- 수정 후 클립명·프레임·FPS와 기존 클립 보존을 상세 조회로 확인한다.

## 6. Object_Player_Gun 개별 익스포트

**대상 스킬**: 게임개발_프리셋_파일_익스포트

**"presetId"**: `Object_Player_Gun`

**업무**
- 문자열 ID 단건으로 export하고 Unity 재임포트를 완료한다.
- `confirmed`·`reuse`는 변경하지 않는다.
- 노드 생성·프리셋 생성·팝업·컨트롤·애드온 코드는 기존 오브젝트 수정 범위와 무관해 제외한다.
- 컨셉·모듈 질문은 신규 설계나 공유 계약 변경이 없어 제외한다.
- `유니티엔진_씬_검증`은 사용자 지시에 따라 실행하지 않는다.
