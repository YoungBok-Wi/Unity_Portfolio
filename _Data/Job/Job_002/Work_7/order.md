# 업무지시서

## 1. 플레이테스트 대상 조회·계획 갱신

**대상 스킬**: QA_유니티게임개발_플레이테스트_계획

**"taskContent"**: Job_001 시나리오(`_Temp/QA/시나리오_Scene_Lobby.md`·치트 명세)를 이번 수정 범위에 맞춰 갱신

**업무**

- 선행 `QA_유니티게임개발_플레이테스트_질문`으로 두 씬의 조작 항목 변화를 조회한다
- 추가 시나리오: PlayerPrefs 초기화 후 첫 실행(Gun 잠금·배지 없음), 피격 후 무입력 정지, 방 경계 벽, 근접 슬롯, 데미지 팝, HUD 이력 9방 이상, 보스 전조 렌더, 텍스트 ID 노출 0건, 사운드 재생, 캐릭터 화면 높이 비율, Job_001 미실측 표본(방 선택·능력 팝업 취소 입력, 능력 연타, 리롤, Knife 콤보, 경계 회피)
- 치트 명세는 `QA_유니티게임개발_플레이테스트_치트_작성`으로 갱신 (PlayerPrefs 초기화 치트 포함)

## 2. 전체 재평가 실행

**대상 스킬**: QA_유니티게임개발_플레이테스트_테스트

**"taskContent"**: 갱신 시나리오 전 단계 구동·판정·결함 보고

**업무**

- Game 뷰를 16:9 1920x1080으로 맞춘 뒤 판정한다. 화면 캡처를 단계별로 남기고 컨셉아트 유사성 판정을 포함한다
- 결함은 수정하지 않고 재현 절차·실측값·담당 영역(컨셉·데이터·리소스·모듈·프리셋·씬)별 목록을 `## 비고`에 남긴다 — 다음 개선 회차 Job의 입력이다
- 완료 기준: 전 단계 합격·불합격 명시, 콘솔 에러 수집, 플레이 모드 종료 확인. 사용자에게 질문하지 않는다
