# 업무지시서

## 1. 팝업·컨트롤 코드 수정

**대상 스킬**: 게임개발_프리셋_파일_팝업_코드_작성

**"taskContent"**: HUD 데미지 팝·이력 상한 표시, 로비 카드 상태 표시 로직 수정

**업무**

- 근거: `_Data/Job/Job_001/Work_6/result.md` `## 비고` "프리셋 구성" 항목과 Work_4(모듈) 레포트의 명중 통지 API
- `Popup_HUD`: 명중 통지 구독 → 데미지 숫자 팝(월드→스크린 좌표, 풀링), 이력 상한 정책(`게임컨셉` Work_1 갱신본) 반영, HP바 하트 아이콘·이력 점선 표시 요소 필드 선언
- `Popup_Lobby`: 미해금 카드 회색 처리·선택 테두리 파랑, `Text_Core_GunUnlock` 표시 위치 정리, 잠금 클릭 시 `Popup_Notify` 호출, 최고 순번 배지 아이콘 정본 사용
- 컨트롤(`게임개발_프리셋_파일_컨트롤_코드_작성`): `Control_RoomHistoryItem` 점선·`Control_AbilityCard` 등 필요한 필드 추가. 선언 필드는 `[SerializeField]`
- 후속 `유니티엔진_컴파일_실행` 통과

## 2. 오브젝트 코드 수정

**대상 스킬**: 게임개발_프리셋_파일_오브젝트_코드_2D_사이드뷰_캐릭터_작성

**"taskContent"**: Gun 플레이어 전용 스프라이트 동작명 배선과 보스 전조 렌더 수정

**업무**

- `Object_Player_Gun`: `Idle`·`Move`를 Work_3이 제작한 `Idle_Gun`·`Move_Gun` 프레임으로 재생
- `Telegraph.prefab`(`Battle` 모듈 소속이면 모듈 담당이므로 확인 후 소속에 맞는 스킬로): 렌더 안 되는 원인(스프라이트 참조·머티리얼·스케일) 실측 후 수정
- 후속 `유니티엔진_컴파일_실행` 통과

## 3. 프리셋 구성·익스포트

**대상 스킬**: 게임개발_프리셋_파일_팝업_구성

**"taskContent"**: 코드가 선언한 필드 배선과 컨셉아트 요소 반영, 프리팹 익스포트

**업무**

- 팝업 구성 → 컨트롤 구성 → 오브젝트 구성(`게임개발_프리셋_파일_오브젝트_구성`) 순. HUD 하트 아이콘·이력 점선, 로비 중앙 요리사 일러스트(Work_3 산출) 배치, `Popup_Notify` 버튼 라벨 폭 확인
- 16:9(1920x1080) Game 뷰 기준으로 `qa_ui` 텍스트 판정을 통과시킨다
- `게임개발_프리셋_파일_익스포트`로 반영하고, 씬 반영이 필요하면 `유니티엔진_씬_셋업_실행`
- 완료 기준: 컴파일 에러 0건, 익스포트 success, 두 씬 플레이 진입 에러 0. 사용자가 자율 진행을 지시했으므로 레이아웃 판단은 스스로 확정한다. `confirmed`·`reuse` 값은 변경하지 않으며 막힘은 우회하지 않고 보고한다
