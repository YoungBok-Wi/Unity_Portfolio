# 업무지시서

## 1. 게임컨셉·밸런스컨셉 갱신

**대상 스킬**: 게임개발_구성_컨셉_게임_작성

**"taskContent"**: Job_001 플레이테스트가 지목한 컨셉 결손을 `게임컨셉`·`밸런스컨셉`에 보완하고 검증

**업무**

- 근거: `_Data/Job/Job_001/Work_6/result.md` `## 비고` "컨셉" 항목. 선행 `게임개발_구성_컨셉_질문`으로 현재 문서를 조회한 뒤 필요한 항목만 수정한다
- `게임컨셉`: 방 이력 표시 상한 정책(HUD 슬롯 8개 초과 시 처리 — 스크롤·압축·최근 N개 중 택1), 로비 최고 순번 배지 아이콘 정본(별 배지, 아이콘 ID 지정), 무입력 시 플레이어 정지(피격 넉백 후 자동 정지) 원칙, 방 좌우 경계(벽) 존재 원칙
- `밸런스컨셉`(`게임개발_구성_컨셉_밸런스_작성` → 검증): 무입력 생존 시간 목표(현재 실측 약 12초), 플레이어 넉백 거리·시간, 방 폭·벽 위치, 근접 슬롯 대기 거리
- 완료 기준: `게임개발_구성_컨셉_게임_검증`·`게임개발_구성_컨셉_밸런스_검증` 합격

## 2. 리소스컨셉 갱신

**대상 스킬**: 게임개발_구성_컨셉_리소스_작성

**"taskContent"**: 캐릭터 화면 높이 비율 규격과 Gun 캐릭터 실루엣·사운드 목록 확정

**업무**

- 캐릭터·적·보스의 "화면 높이 비율" 기준을 규격에 추가한다 (컨셉아트 플레이어 ≈40%, 실측 7.7% — 카메라 `orthographicSize`와 PPU 128·잉크 높이 관계를 명시하고 조정 주체를 씬 카메라로 확정)
- Gun 캐릭터 전용 `Idle`·`Move` 시트(케첩 건 실루엣)를 제작 목록에 추가하고, 로비 중앙 요리사 일러스트 규격을 정의한다
- 사운드: 기존 타입 `BGM_Casual`(Lobby·Battle)·`SFX_Casual_Battle`(Attack·Hit·Die)·`SFX_Casual_Progress`(LevelUp·Unlock)에 entry가 없으므로 제작 대상 목록과 길이·포맷 규격을 정한다
- 완료 기준: `게임개발_구성_컨셉_리소스_검증` 합격

## 3. 씬설정 갱신·셋업

**대상 스킬**: 게임개발_구성_컨셉_씬_작성

**"taskContent"**: `Scene_Lobby` UI에 `Popup_Notify` 등재 등 씬설정 보완·검증·셋업 반영

**업무**

- `Scene_Lobby` UI 목록에 `Popup_Notify`를 추가한다 (Gun 잠금 클릭·설정 적용 알림용). `Scene_Game`은 업무 1·2 변경이 영향을 주는 항목만 갱신한다
- `게임개발_구성_컨셉_씬_검증` 합격 후 `유니티엔진_씬_셋업_실행`으로 두 씬에 반영한다 (사용자 영역 오브젝트 오버라이드 소실 대조 포함)
- 완료 기준: 두 씬 셋업 success·컴파일 에러 0건. `confirmed`·`reuse` 값은 변경하지 않으며 막힘은 우회하지 않고 보고한다
