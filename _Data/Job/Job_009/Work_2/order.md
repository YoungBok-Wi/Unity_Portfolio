# 업무지시서

## 1. 모듈 현황 조회

**대상 스킬**: 게임개발_모듈_질문

**"question"**: 넉백 처리·유닛 FSM·전투 설정·SceneChangeAni_Face를 소유하는 모듈과 원본·참조 계약

**업무**

- `Unit`·`PlayerCharacter`·`Enemy`·`Boss`·`Game`의 설계·코드·프리팹 원본과 호출부를 확인한다.
- 기존 FSM 상태 전환 API와 넉백 구현, Face 타일 생성·그래픽 배선 위치를 확정한다.

## 2. 컨셉 정의 조회

**대상 스킬**: 게임개발_구성_컨셉_질문

**"question"**: `Work_1`이 확정한 넉백 FSM·설정 위치·Face 얼굴 타일 요구

**업무**

- 구현 기준과 수치·리소스 정의처를 확인한다.

## 3. 데이터 정의 조회

**대상 스킬**: 게임개발_구성_데이터_질문

**"question"**: 현재 넉백 거리·시간·스턴 값과 코드 생성 계약

**업무**

- 기존 데이터 중 유지할 값과 인스펙터로 이동하지 않을 항목을 확인한다.

## 4. 리소스 정의 조회

**대상 스킬**: 게임개발_구성_리소스_질문

**"question"**: `Icon_Casual_Face/Chef` 출력 경로·Sprite 임포트·투명 배경 상태

**업무**

- Face 타일에 배선할 기존 얼굴 스프라이트를 확정한다.

## 5. 프리셋 영향 조회

**대상 스킬**: 게임개발_프리셋_파일_질문

**"question"**: 넉백 가능한 플레이어·적·보스 프리팹의 FSM 구조와 참조 계약

**업무**

- 새 상태 컴포넌트가 필요한 프리팹 전수를 확정한다.

## 6. 모듈 설계·코드·프리팹 수정

**대상 스킬**: 게임개발_모듈_폴더_작성

**"moduleIds"**: 조회로 확정한 `Unit`·`PlayerCharacter`·`Enemy`·`Boss`·`Game` 중 실제 변경 대상

**"content"**: 넉백 FSM 상태와 전투 설정 노출, Face 전환 타일 얼굴 그래픽 배선

**업무**

- 넉백 이동 곡선과 종료 후 스턴을 하나의 FSM 상태가 소유하고 완료 후 각 유닛의 정상 상태로 복귀하게 한다.
- 기존 비-FSM 넉백 갱신과 중복 실행 경로를 원인 위치에서 제거한다.
- 곡선과 스턴 시간을 전투 설정 인스펙터에서 직렬화해 상태가 참조하도록 한다.
- `SceneChangeAni_Face`의 모든 타일 그래픽이 기존 얼굴 스프라이트를 사용하도록 원본 프리팹·코드를 구성한다.

## 7. 모듈 익스포트

**대상 스킬**: 게임개발_모듈_폴더_익스포트

**"moduleIds"**: 업무 6의 실제 변경 모듈

**업무**

- 원본을 엔진 사본에 반영하고 재임포트·등록 상태를 검증한다.

## 8. Unity 컴파일

**대상 스킬**: 유니티엔진_컴파일_실행

**"changedPaths"**: 업무 6·7에서 변경된 스크립트와 프리팹

**업무**

- 실제 재컴파일 완료와 콘솔 오류 `0건`을 확인한다.
