# 업무지시서

## 1. 얼굴 리소스 타입 조회

**대상 스킬**: 게임개발_구성_리소스_질문

**"question"**: `Icon_Casual_Face` 타입 설명·출력 슬롯과 `Chef` 실제 파일 규격 대조

**업무**

- 타입의 현재 설명·출력 슬롯과 `Chef` 파일의 실제 결과 크기·점유율을 조회한다.
- 기록값 `232px·0.90625`와 실측값 `252px·0.984375`의 불일치를 확인한다.

## 2. 얼굴 리소스 타입 정정

**대상 스킬**: 게임개발_구성_리소스_타입_구성

**"content"**: 실제 투명 배경 얼굴 리소스 규격을 타입 정본에 반영

**업무**

- `Icon_Casual_Face` 설명과 출력 슬롯의 결과 크기를 `252px`, 점유율을 `0.984375`로 정정한다.
- 파일·프롬프트·자동화·`confirmed`·`reuse`는 변경하지 않는다.
- 타입이 이미 등록됐고 새 파일·기본 출력 제작이 없으므로 타입 생성·업로드·파일 생성·구성 체인은 제외한다.
