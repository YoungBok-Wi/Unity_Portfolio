# 업무지시서

## 1. 대상 프리셋 조회

**대상 스킬**: 게임개발_프리셋_파일_질문

**"question"**: 넉백 가능한 플레이어 2종·적 3종·보스 2종의 FSM 상태 노드와 `Work_2`의 새 상태 컴포넌트 배선 요구

**업무**

- 실제 변경 대상과 원본·export 사본 구조를 확인한다.
- 기존 상태 노드 패턴과 Missing 참조를 확인한다.

## 2. 관련 컨셉·모듈·리소스 조회

**대상 스킬**: 게임개발_구성_컨셉_질문

**"question"**: 넉백 FSM 상태와 Face 타일 얼굴 그래픽 구성 기준

**업무**

- `Work_1`·`Work_2`의 공개 계약을 프리셋 배선 기준으로 확인한다.

## 3. 모듈 계약 조회

**대상 스킬**: 게임개발_모듈_질문

**"question"**: 새 넉백 상태 컴포넌트와 전투 설정 필드, Face 전환 프리팹 공개 필드

**업무**

- 컴파일된 타입·직렬화 필드와 프리팹 소유 경계를 확인한다.

## 4. 얼굴 리소스 조회

**대상 스킬**: 게임개발_구성_리소스_질문

**"question"**: Face 타일에 사용할 `Icon_Casual_Face/Chef` 스프라이트

**업무**

- 실제 에셋 경로와 투명 배경·Sprite 타입을 확인한다.

## 5. 유닛 오브젝트 프리팹 구성

**대상 스킬**: 게임개발_프리셋_파일_오브젝트_구성

**"fileIds"**: 넉백 가능한 플레이어 2종·적 3종·보스 2종

**"content"**: 각 FSM에 넉백 상태 노드·컴포넌트 추가 및 상태 참조 배선

**업무**

- 기존 상태 노드 패턴을 재사용해 넉백 상태를 추가한다.
- 모든 대상에서 상태 중복·Missing 스크립트·Missing 참조가 없게 구성한다.
- `SceneChangeAni_Face`가 모듈 프리팹 소유이면 `Work_2` 산출물을 변경하지 않고 검증만 한다.

## 6. 프리셋 익스포트

**대상 스킬**: 게임개발_프리셋_파일_익스포트

**"scope"**: 업무 5에서 변경된 오브젝트 프리팹 전수

**업무**
