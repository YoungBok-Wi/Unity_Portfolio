# 업무지시서

## 1. 관련 컨셉 조회

**대상 스킬**: 게임개발_구성_컨셉_질문

**"question"**: 넉백·피격 FSM, 넉백 곡선·스턴 설정 정의처, Face 씬전환 타일 그래픽의 현재 정본

**업무**

- `게임컨셉`과 `리소스컨셉`에서 기존 넉백·FSM·Face 전환 요구를 실측한다.
- 현재 수치값은 바꾸지 않고 설정 위치와 상태 책임만 개정 대상으로 확정한다.

## 2. 게임컨셉 수정

**대상 스킬**: 게임개발_구성_컨셉_게임_작성

**"content"**: 넉백을 명시적 FSM 상태로 처리하고 곡선·종료 후 스턴 시간을 전투 설정 인스펙터에서 조정, Face 전환은 얼굴 타일의 대각선 순차 등장·소멸

**업무**

- 넉백 시작·이동·종료 후 스턴·다음 상태 복귀의 책임을 FSM 상태로 명시한다.
- 넉백 이동 곡선과 종료 후 스턴 시간을 기존 전투 설정 인스펙터의 조정 항목으로 명시한다.
- Face 씬전환의 모든 타일이 플레이어 얼굴 그래픽을 표시하도록 명시한다.

## 3. 게임컨셉 검증

**대상 스킬**: 게임개발_구성_컨셉_게임_검증

**"scope"**: 넉백 FSM·설정 정의처·Face 얼굴 타일 연출

**업무**

- 수정 요구가 정본에 빠짐없이 반영됐는지 검증한다.

## 4. 리소스컨셉 수정

**대상 스킬**: 게임개발_구성_컨셉_리소스_작성

**"content"**: `SceneChangeAni_Face` 전 타일에 기존 `Icon_Casual_Face/Chef` 얼굴 그래픽 사용

**업무**

- 신규 이미지 생성 없이 기존 투명 얼굴 리소스를 모든 타일에 적용하는 규격을 명시한다.
- 타일 스케일 애니메이션 중 얼굴 비율·투명 배경·식별성을 보존한다.

## 5. 리소스컨셉 검증

**대상 스킬**: 게임개발_구성_컨셉_리소스_검증

**"scope"**: Face 씬전환 얼굴 타일 그래픽 규격

**업무**

- 타일별 얼굴 그래픽과 기존 리소스 재사용 요구가 정본에 반영됐는지 검증한다.
