# 업무지시서

## 1. 두 씬 상태 조회

**대상 스킬**: 유니티엔진_씬_질문

**"scope"**: `Scene_Game`, `Scene_Lobby`

**업무**

- setup 전 씬 계층·프리팹 오버라이드·카메라·씬 고유 참조를 기록한다.
- `[Global]/[SceneChangeManager]`의 Face 전환 프리팹과 얼굴 타일 참조 상태를 확인한다.

## 2. 두 씬 셋업 반영

**대상 스킬**: 유니티엔진_씬_셋업_실행

**"sceneName"**: `Scene_Game`, `Scene_Lobby`

**업무**

- `Work_2`·`Work_3`의 모듈·프리셋 산출물을 두 씬에 반영한다.
- setup 전후 차이를 대조해 씬 고유 값을 보존한다.

## 3. 씬 고유 값 복원

**대상 스킬**: 유니티엔진_씬_구성

**"sceneName"**: `Scene_Game`, `Scene_Lobby`

**"content"**: setup이 초기화한 카메라·플레이어 상주·씬 고유 참조만 이전 실측값으로 복원

**업무**

- `[Global]` 하위 오버라이드는 남기지 않는다.
- Face 타일 그래픽은 원본 프리팹 정의를 사용한다.

## 4. 씬·런타임 최종 검증

**대상 스킬**: 유니티엔진_씬_검증

**"scope"**: 두 씬 계층·직렬화·컴파일·런타임 Face 전환 화면과 넉백 FSM 전환

**업무**

- Missing 스크립트·참조·구 매니저·`[Global]` 오버라이드 `0건`을 확인한다.
- 모든 Face 타일이 플레이어 얼굴 스프라이트를 표시하고 대각선 순서로 등장·소멸하는 캡처를 확보한다.
- 넉백 피격 시 새 FSM 상태 진입, 곡선 이동, 설정된 스턴 뒤 정상 상태 복귀를 실측한다.
- 컴파일 오류와 런타임 콘솔 오류 `0건`을 확인한다.
