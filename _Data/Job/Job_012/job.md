# 전체 버튼 표준 Control_Button 구조 통일

## 목표

- `Animator_Button`을 사용하는 전체 게임 UI 버튼을 라이브러리 표준 `Control_Button` 프리셋 구조로 통일한다.
- 버튼별 표시·레이아웃·클릭 배선과 기존 동작을 보존한다.

## 범위

- 표준 `Control_Button` 구조와 변형별 용도를 조회한다.
- 게임 `컨트롤`·`팝업` 내부의 비표준 버튼을 전수 확인한다.
- 대상 프리셋 원본을 수정하고 개별 익스포트·재임포트한다.

## 제약

- 직접 모드로 수행하고 서브에이전트를 만들지 않는다.
- `유니티엔진_씬_검증` 스킬은 실행하지 않는다.
- `confirmed`·`reuse`는 변경하지 않는다.
- 기존 사용자 작업 트리 변경을 수정하거나 커밋하지 않는다.
