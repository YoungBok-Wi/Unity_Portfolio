# Kitchen Riot - 게임컨셉

## 개요
- 장르: 2D 사이드뷰 캐주얼 로그라이트 액션
- 플랫폼: PC (Windows)
- 타겟 유저: 짧은 런을 반복하는 캐주얼 액션 유저
- 타겟 유저: 포트폴리오 평가자 (FSM·물리·데이터 구동 구조 확인)

## 핵심 컨셉
- 테마: 주방 요리사가 반란을 일으킨 식재료(과일 적)를 소탕한다 — 기존 `Casual` 계열 리소스(주방 타일·과일 애니메이션시트·Knife/Gun 무기)를 재사용한다
- 런 구조: 로비에서 캐릭터를 고르고 시작하면 `Scene_Game`에서 방을 하나씩 클리어하며 전진하고, 보스방 클리어 또는 사망으로 런이 끝나 로비로 돌아간다
- 방 선택: 방 클리어마다 다음 방 2택 선택지 팝업이 열리고, 선택지 세트는 [Battle/Heal]·[Heal/Ability]·[Battle/Boss]·[Battle/Battle] 4가지 중 랜덤이다 (Boss 선택지 출현 최소 순번·강제 순번은 `밸런스컨셉` 위임)
- 방 종류: Battle(적 웨이브 전부 처치), Heal(HP 회복 후 즉시 클리어), Ability(강화 3택1 후 즉시 클리어), Boss(보스 1종 처치 시 런 승리)
- 방 정보 UI: 지나온 방 이력(종류 아이콘 열)을 HUD에 항상 표시하고, 방 선택 팝업의 각 선택지에 다음 방 적 구성 미리보기(적 종류·마릿수)를 표시한다
- 방 이력 상한: HUD 이력 슬롯 수는 고정이고 슬롯을 넘는 순번부터는 "최근 N개"만 표시한다 (스크롤·압축 채택 안 함 — 전체 위치는 현재 방 순번 숫자가 대신한다, 슬롯 수 N은 `밸런스컨셉` 위임)
- 방 경계: 모든 방은 좌우 끝에 벽이 있어 플레이어·적·투사체가 방 밖으로 나가지 못한다 (방 폭·벽 위치·적 등장 위치는 `밸런스컨셉` 위임)
- 캐릭터 해금: Knife는 초기 사용 가능, Gun은 5번째 방 클리어 시점에 영구 해금되어 저장된다 (런 결과와 무관)
- 최고 순번 배지: `Scene_Lobby` 캐릭터 카드 위에 저장된 최고 도달 방 순번을 별 배지 아이콘 `Icon_Casual_Room/Best`와 숫자로 표시한다 (방 종류 아이콘 재사용 금지 — 별 아이콘은 `리소스컨셉` 제작 목록에 둔다)
- 재화: Crumb 단일 재화 — 적 처치 시 낙하해 플레이어가 주우면 획득하고, Ability 방의 3택 다시 뽑기(리롤)에 소모하며 런 종료 시 소멸한다 (획득 총량을 결과 팝업 점수로 표시)

**캐릭터**
   - Knife: 근접 3단 콤보 — 공격 입력마다 다음 단으로 이어지고 3단은 넉백이 크다, 판정은 전방 사각 박스로 범위 안 적 전부 다중 명중
   - Gun: 원거리 연사 — 공격 입력 유지 시 정지 상태로 전방에 투사체를 연사, 투사체는 첫 충돌 적에게 단일 명중 (MultiHit 능력으로 관통 수 증가)

**적·보스**
   - Apple: 근접 공격형 — 추격 후 근접 거리에서 물기 공격
   - Watermelon: 탱킹형 — HP가 높고 느리며 몸통 박치기, 넉백 거리 짧음
   - Banana: 원거리형 — 사거리 유지 거리를 지키며 껍질 투사체를 직선 발사
   - Pumpkin: 근접형 보스, FSM 상태 5개 — Idle(등장·패턴 간 대기) → Chase(추격) → Slam(근접 전조 후 전방 광역 내려찍기) / Charge(원거리 전조 후 좌우 돌진) → Enrage(HP 절반 이하, 이동속도·패턴 빈도 상승, 이후 Chase로 복귀)
   - Pineapple: 원거리형 보스, FSM 상태 5개 — Idle → Retreat(사거리 유지 후퇴) → Spike(가시 투사체 3연발) / Rain(전조 표시 후 지정 구역 가시 낙하 광역) → Enrage(HP 절반 이하, Rain 구역 수 증가, 이후 Retreat로 복귀)
   - 보스 공통: 넉백 면역, 전조 없는 즉발 광역 없음, 전조 표시는 패턴 시작 전 재생 — 형태는 바닥에 납작한 가로 타원(폭 > 높이, 중심은 대상 발밑 바닥 y)으로 고정

**능력**
   - Attack: 공격력 증가
   - AttackSpeed: 공격속도 증가
   - MaxHp: 최대 HP 증가 (증가분만큼 즉시 회복)
   - MoveSpeed: 이동속도 증가
   - HealMacaron: 즉시 HP 회복 (일회성)
   - MultiHit: Knife는 한 공격의 명중 상한 증가, Gun은 투사체 관통 수 증가
   - 획득 규칙: Ability 방에서 6종 중 무작위 3종을 제시하고 1개 선택, 같은 능력 중복 획득 가능하며 런 종료 시 초기화 (단계별 수치는 `밸런스컨셉` 위임)

**조작 입력**
   - 이동: 좌우 (키보드 A/D·화살표, 게임패드 좌스틱) — Input System 사용
   - 점프: 1단 점프 (Banana·Pineapple 투사체 회피 수단)
   - 공격: 수동 입력 — Knife는 누를 때마다 콤보 1단, Gun은 누르는 동안 연사
   - 일시정지·취소: Esc·게임패드 Start — `Scene_Game`은 일시정지 팝업, `Scene_Lobby`는 종료 확인 팝업
   - 회피(대시): 없음 — 사거리·이동속도 차와 점프로 회피가 성립해 입력 수를 줄인다
   - 무입력 정지: 이동 입력이 없으면 플레이어는 즉시 제자리에 선다 — 피격 넉백은 정해진 거리·시간만 이동한 뒤 자동 정지하고 잔여 속도를 남기지 않는다 (넉백 거리·시간은 `밸런스컨셉` 위임)
   - 적 접촉: 적과 플레이어의 물리 콜라이더는 서로 밀지 않는다 — 겹침 허용(적↔플레이어 물리 충돌 해소 없음, 접촉 피해는 정지 거리·판정 트리거로만), 플레이어 위치는 이동 입력·피격 넉백으로만 바뀐다

**저장**
   - 저장 항목: Gun 해금 여부, 마지막 선택 캐릭터, 최고 도달 방 순번, BGM·SFX 볼륨
   - 런 중 저장: 없음 — 런 중 이탈·종료 시 런은 소멸한다

## 기획 원칙
- 데이터 구동: 캐릭터·적·보스·방·능력·웨이브 수치는 테이블·고정값으로만 정하고 코드에 리터럴을 두지 않는다
- 정본 단일화: 대상 ID는 본 문서 "정본 ID"에서만 확정하고 수치는 `밸런스컨셉`에서만 확정한다
- 짧은 런: 한 런은 보스까지 6~10방으로 끝나 반복 시작 비용이 낮다 (목표 시간은 `밸런스컨셉` 위임)
- 선택의 가시성: 모든 선택(방·능력)은 결과를 미리 보여 준 뒤 고르게 한다
- 리소스 재사용: `Casual` 계열 기존 리소스로 표현 가능한 요소는 신규 제작하지 않는다

**액션 장르 표준 판정**
   - 루프 표준(조우→교전→소탕→보상→전진): 반영 — Battle 방 안에서 웨이브 처치·Crumb 낙하까지 완결되고 선택 팝업으로 다음 방에 빈틈 없이 이어진다
   - 파워 판타지: 반영 — 능력이 쌓인 후반 방에서 초반 등급 일반 적은 1~2타에 처치되고 Knife 박스 판정·Gun 관통으로 밀집 무리가 함께 소멸한다
   - 타격 3요소 동시성: 반영 — 히트 이펙트·타격음·데미지 표시를 명중 프레임에 동시 재생하고 Knife 3단·보스 피격에 히트스톱을 둔다
   - 이동/공격 리듬: "정지 공격 + 이동으로 회피"로 확정 — 이동 중 공격 입력 시 즉시 정지 후 공격, 공격 모션 중 이동 입력은 무시(취소 불가), 공격 입력은 모션 후반 선입력 허용(Knife 콤보 연결)
   - 보스 문법: 반영 — 전조 표시 후 광역 패턴, HP 절반 이하 Enrage 상태 추가

**전투 파라미터 항목**
   - 공격 주기: 캐릭터별 공격속도 항목 (캐주얼 관행 대역 안, 값은 `밸런스컨셉`)
   - 이동속도: 캐릭터 이동속도·적 이동속도 항목, 적은 캐릭터 대비 비율로 둔다 (값은 `밸런스컨셉`)
   - 넉백: 일반 적 피격 넉백 채택 — 거리·완료 시간 항목 (값은 `밸런스컨셉`), 보스는 면역
   - 범위 판정: Knife 전방 사각 박스 폭·높이 항목(적 히트박스보다 크게 두어 다중 명중 성립), Gun 투사체 충돌 단일 명중·관통 수 항목 (값은 `밸런스컨셉`)
   - 군중 교전 기준: 화면 내 최대 적 수 항목, 스펙 우위 시 웨이브 소멸 목표 시간 항목 (값은 `밸런스컨셉`)

## 게임 루프
게임을 구성하는 핵심 루프와 각 루프의 단계 흐름이다.

**런 루프**
- 캐릭터 선택: `Scene_Lobby`에서 Knife·Gun 중 선택 (Gun 미해금이면 잠금 표시·선택 불가)
- 시작: 시작 입력으로 `Scene_Game` 진입, 1번째 방은 항상 Battle
- 방 진행: 방 종류별 클리어 조건 달성 → 방 선택 팝업(2택, 적 미리보기) → 선택 → 다음 방 즉시 구성·입장 (씬 전환 없음, 방 순번 +1)
- 성장: Ability 방 강화 누적으로 같은 등급 적의 처치 시간이 짧아진다 (처치 시간 목표 항목은 `밸런스컨셉`)
- 종료: Boss 방 클리어(승리) 또는 HP 0(패배) → 결과 팝업(도달 순번·Crumb 총량·Gun 해금 알림) → `Scene_Lobby`

**전투 루프**
- 조우: 웨이브 적이 방 좌우 끝에서 등장해 플레이어를 추격한다
- 교전: 정지 공격으로 타격, 이동·점프로 회피
- 소탕: 웨이브 전멸 시 다음 웨이브 등장, 마지막 웨이브 전멸 시 방 클리어
- 보상: 처치 시 Crumb 낙하·수거

## 필수 판정
- 진행 변화 구간: 방 순번 — 순번이 오를수록 적 스탯·웨이브 구성이 성장한다 (곡선은 `밸런스컨셉`)
- 판 간 진행: 방 클리어 → 방 선택 팝업 → 선택 즉시 같은 씬 안에서 다음 방 구성·입장, 런 종료 시에만 `Scene_Lobby`로 씬 전환
- 일시정지: `Scene_Game`에서 Esc·Start로 일시정지 팝업 — 게임 시간 정지, 재개·설정·포기(로비로) 제공
- 이탈 경로: 일시정지 팝업 "포기" → `Scene_Lobby` (런 소멸), `Scene_Lobby` 종료 확인 팝업 → 앱 종료
- 종료 조건: 승리 — Boss 방 보스 처치, 패배 — 플레이어 HP 0
- 화면 추적 기준: 사이드뷰 카메라가 플레이어 X를 추적하고 Y는 고정, 방 좌우 경계에서 클램프

## 장르 요소
**히트 이펙트**
   - 소비처: `Scene_Game` 적·보스·플레이어 오브젝트
   - 내용: 명중 프레임에 피격 위치에 `Illust_Casual_Hit/Impact` 재생

**히트스톱**
   - 소비처: `Scene_Game` 전투 진행
   - 내용: Knife 3단·보스 피격에 짧은 시간 정지 동시 재생, 1·2단·Gun 명중은 연사 뭉개짐 방지를 위해 제외 (시간은 `밸런스컨셉`)

**타격 사운드**
   - 소비처: `Scene_Game` 적·보스·플레이어 오브젝트
   - 내용: 명중 프레임에 `SFX_Casual_Battle/Hit`, 공격 시작에 `SFX_Casual_Battle/Attack`, 처치에 `SFX_Casual_Battle/Die`

**넉백·경직**
   - 소비처: `Scene_Game` 적 오브젝트
   - 내용: 일반 적 피격 시 명중 프레임에 후방 넉백·짧은 경직, 보스 면역. 플레이어도 피격 시 후방 넉백 후 자동 정지 (거리·시간은 `밸런스컨셉`)

**데미지 표시**
   - 소비처: `Scene_Game` HUD
   - 내용: 명중 프레임에 피격 위치 위로 데미지 숫자 팝 후 상승·소멸

**처치 연출**
   - 소비처: `Scene_Game` 적·보스 오브젝트
   - 내용: 사망 애니메이션(`AnimationSheet_Casual_Enemy/*_Die`)과 `Illust_Casual_Splatter/Death` 동시 재생, Crumb 낙하

**공격 연출**
   - 소비처: `Scene_Game` 플레이어 오브젝트·투사체 오브젝트
   - 내용: Knife 휘두름에 `Illust_Casual_Slash/Knife` 궤적, Gun 투사체는 `Illust_Casual_Projectile/Gun`

**보스 전조**
   - 소비처: `Scene_Game` 보스 오브젝트
   - 내용: Slam·Charge·Rain 시작 전 바닥에 납작한 가로 타원(폭 > 높이, 중심은 범위 발밑 바닥 y) 범위 표시를 재생한 뒤 패턴 발동 — 세로 타원·바닥 위 부양 표시 금지
